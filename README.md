# Convite · Fuenteovejuna

Site de convite e confirmação de presença para Fuenteovejuna (Vitor Heitor como Mengo).

- `index.html` — o site inteiro. Datas, local e URL do backend ficam no bloco `CONFIG`/`DATAS` no fim do arquivo.
- `apps-script/Code.gs` — backend no Google Apps Script, vinculado à planilha "Fuenteovejuna — Confirmações" (conta vhsousa2012). Publicado como Web App.
